### Overview
Built from the ground up for the Organization of Multimedia Artists at STI College. The platform gives student and alumni artists a dedicated space to showcase portfolios, process event and print transactions via Xendit, store high-res media securely on AWS S3, and interact in real time using Socket.io and Redis.

### Key Features
- **Artist Portfolios & Galleries**: High-resolution creative media showcase with S3 presigned uploads and Exif extraction.
- **Payment Processing**: Integrated Xendit checkout gateway for merchandise and organization event tickets.
- **Real-Time Collaboration**: Live community chat and announcements powered by Socket.io and Upstash Redis.
- **Fast Search**: Algolia-powered instant search across creators, creative tags, and portfolio assets.
