### Overview
Built for our 4th-year college Technopreneurship subject at DFCAMCLP alongside my internship (held every Friday), CND Upraze is a full-stack digital services and e-commerce platform. As the sole developer behind the entire application, I architected both the decoupled React 19 frontend and the Laravel 11 backend service core, wrapping the solution in Docker for containerized deployment.

### Key Features
- **Administrative Command Center**: High-density operational cockpit featuring real-time financial trajectory visualization, client telemetry, and service package management.
- **3D Studio Integration**: Interactive visual model manipulation embedded in a responsive Bento-style layout for proprietary business workflows.
- **Groq-Accelerated AI Assistant**: Task automation and intelligent customer support chatbot delivering fast LLM inference times.
- **Payment & Order Pipeline**: End-to-end checkout with automated invoice generation, Xendit/PayMongo payment callbacks, and instant customer notifications.
- **Optimized Communications**: Support hub with database indexing on message status and sender tracking for fast message retrieval.
