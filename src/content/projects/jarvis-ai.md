### Overview
An experimental multi-agent AI system built to see how far autonomous agent cooperation could go. Using Microsoft AutoGen and FastAPI, I set up a network of specialized agents that talk to one another over an internal message bus to break down and solve complex engineering tasks, with a real-time Vue 3 dashboard showing live agent conversations.

### Key Features
- **Multi-Agent Orchestration**: AutoGen agent roles collaborating on code generation, research, and data synthesis.
- **Real-Time WebSocket Feed**: Live streaming of agent reasoning, token outputs, and task handoffs.
- **Provider Agnostic**: Unified integration supporting OpenAI, Anthropic Claude, and Google Gemini models.
- **Modern Dashboard**: Responsive Vue 3 frontend built with Vite and TailwindCSS.
